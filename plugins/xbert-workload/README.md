# XBert Team Workload

See who's overloaded, who's running over estimate, and how to rebalance.

## What it does
- Pulls active assignments, time logged, and estimate variance from XBert
- Flags overloaded vs under-utilised team members
- Suggests specific, hours-quantified rebalances
- Groups overdues by client so you can call ahead

## Prerequisites
- XBert account with team tracking enabled
- Tasks assigned to team members in XBert

## Usage
After installing, type:

    /workload

in any Claude chat (Desktop or Code). Add a team member name to deep-dive on one person:

    /workload Sarah
