# XBert BAS Prep (AU)

Pre-lodgement BAS readiness check for Australian clients. Verifies the books are ready and produces a Word audit document for the file.

## What it does
- Pulls bank reconciliation, GST, PAYG-W, payroll, super, fixed assets, AP, AR and outstanding XBerts from XBert
- Runs the 13-point readiness checklist
- Compares the period to the prior BAS quarter and flags variances
- Produces a Word audit document with a unique check reference ID and QMS certification

## Prerequisites
- XBert account
- Client connected to an Australian-domiciled ledger
- GST registration and BAS reporting period configured

## Usage
After installing, type:

    /bas-prep

in any Claude chat (Desktop or Code).
