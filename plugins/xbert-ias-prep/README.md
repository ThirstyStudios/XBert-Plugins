# XBert IAS Prep (AU)

Pre-lodgement IAS readiness check for Australian clients. Verifies the books are ready and produces a Word audit document for the file.

## What it does
- Pulls bank reconciliation, payroll, PAYG-W, super and outstanding XBerts from XBert
- Runs the IAS readiness checklist with W1-W5 verification
- Reconciles PAYG-W against payrun totals and the PAYGW liability account
- Produces a Word audit document with a unique check reference ID and QMS certification

## Prerequisites
- XBert account
- Client connected to an Australian-domiciled ledger
- Client has PAYG withholding obligations or pays PAYG instalments

## Usage
After installing, type:

    /ias-prep

in Claude Code or Claude Desktop.
