# XBert FX Review

Period-end FX-exposure review with a proposed revaluation journal for partner approval.

## What it does
- Resolves the period's linked FX XBert firings (unrevalued balances, intercompany mismatches, FX bank accounts, FX AR/AP)
- Composes the revaluation journal per balance with source amount, posting rate, period-end rate, gain/loss and offsetting P&L line
- Reconciles intercompany FX mismatches in the same journal
- Captures partner sign-off per line before the journal is posted (plugin proposes; partner posts)

## Prerequisites
- XBert account
- Client connected to a multi-currency ledger
- FX XBerts linked to the FX Review agent in the Connect portal

## Usage
After installing, type:

    /fx-review

in any Claude chat (Desktop or Code).
