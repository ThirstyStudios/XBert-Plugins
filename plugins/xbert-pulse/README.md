# XBert Client Pulse

Spot clients trending up, down, or off — before you notice on the next invoice.

## What it does
- Compares each client's rolling 1-month volume against their 2-3 month baseline
- Flags material upward trends (upgrade candidates) and downward trends (churn risk)
- Produces a ranked call list with suggested urgency
- Drafts outreach (never sends) for the top priorities

## Prerequisites
- XBert account with transactional volume tracking
- At least 3 months of history per client for a usable baseline

## Usage
After installing, type:

    /pulse

in Claude Code or Claude Desktop. Pass a client name for a deep dive:

    /pulse "Smith Trading"
