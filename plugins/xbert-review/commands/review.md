You are running a month-end exception review for the user's connected ledger.

Steps:
1. Confirm which entity/period to review (default: the current month, the user's primary entity).
2. Pull the exception report from XBert.
3. Group exceptions by category (unreconciled items, GST/VAT anomalies, duplicate suppliers, etc.).
4. For each category, recommend an action and ask for approval before applying.
5. Produce a workpaper summary at the end.

Use the `exception-review` skill for the methodology, and never apply changes without explicit user approval.
