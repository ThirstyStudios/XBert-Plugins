# XBert Month-End Review

Run a full month-end exception review on a connected ledger with one command.

## What it does
- Pulls open exceptions from XBert
- Groups them by category and materiality
- Walks you through each one, proposing actions but never applying without approval
- Outputs a markdown workpaper at the end

## Prerequisites
- XBert account (Growth tier or above)
- A connected ledger: Xero, QBO, or MYOB

## Usage
After installing, type:

    /review

in any Claude chat (Desktop or Code).
