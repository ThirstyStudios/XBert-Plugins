# XBert Practice Metrics

Monthly partner-meeting one-pager — revenue, lockup, write-offs, service-line P&L, client risk segmentation.

## What it does
- Pulls timesheets, invoices, aged receivables and client data for the reporting month and the prior month
- Computes the standard partner KPI set (revenue, WIP, debtors, lockup days, write-offs)
- Builds a service-line P&L (bookkeeping vs tax vs advisory)
- Calls out material movers vs prior month with commentary
- Bands every client as Red / Amber / Green and lists any band-change since last month
- Produces a Word one-pager plus an Excel companion

## Prerequisites
- XBert account
- XPM connected (for timesheet, WIP and invoicing data)
- Aged receivables and invoice data available via ledger or XPM

## Usage
After installing, type:

    /practice-metrics

in any Claude chat (Desktop or Code).
