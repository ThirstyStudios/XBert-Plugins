# XBert Client Fee Review

Evidence-based annual fee review across the whole client book — per-client cost-to-serve evidence in Word and Excel.

## What it does
- Pulls per-client time, current fee position and six ledger-volume categories (bank transactions, AP, AR, payroll runs, expense claims, manual journals)
- Computes practice medians and categorises every client: Increase / Stable / Decrease / Insufficient data
- Ranks the Increase and Decrease lists by indicated fee delta
- Produces a Word document with the portfolio summary plus a one-page evidence sheet per client
- Exports the full matrix as Excel for downstream pricing tools (e.g. Cass Scott Strategic Pricing)

## Prerequisites
- XBert account
- XPM connected (for timesheet and client data) — or equivalent practice management source
- At least 12 months of completed work and time records for the cohort being reviewed

## Usage
After installing, type:

    /client-fee-review

in any Claude chat (Desktop or Code).
