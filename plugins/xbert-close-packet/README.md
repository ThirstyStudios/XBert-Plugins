# XBert Close Packet

Month-end packet assembled as a single Word/PDF deliverable for the client. Composes balance sheet, P&L with variance commentary, material-journal narrative, KPI page, and outstanding XBerts — partner reviews and sends.

## What it does
- Pulls BS, P&L, cashflow, trial balance, budget, outstanding XBerts, and material journals in one workflow
- Drafts variance commentary scaffolding for each material P&L line
- Drafts narrative for each material journal from description + accounts + prior-period context
- Lists outstanding XBerts inline in the variance section so risks sit beside explanations
- Assembles a Word/PDF with consistent section order — same shape every period

## Prerequisites
- XBert account
- Client ledger with at least one closed accounting period
- Budget loaded in the ledger (recommended; packet still runs without)

## Usage
After installing, type:

    /close-packet

in any Claude chat (Desktop or Code).
