# XBert FBT Prep (AU)

Annual FBT exposure scan for Australian clients. Identifies fringe benefit triggers, estimates the liability, and produces a Word working paper for the file before 21 May.

## What it does
- Scans expense and balance sheet accounts for FBT trigger patterns
- Applies the correct gross-up (Type 1 2.0802 / Type 2 1.8868) and 47% rate
- Identifies minor-benefits exemption opportunities (<$300 infrequent and irregular)
- Estimates Reportable Fringe Benefit candidates (>$2,000 grossed-up value per employee)
- Produces a Word working paper with assumptions and recommended actions

## Prerequisites
- XBert account
- Client connected to an Australian-domiciled ledger
- Full FBT year P&L and balance sheet posted

## Usage
After installing, type:

    /fbt-prep

in any Claude chat (Desktop or Code).
