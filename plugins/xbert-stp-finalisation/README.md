# XBert STP Finalisation (AU)

Annual STP Phase 2 finalisation check for Australian clients. Verifies every employee's YTD wages, PAYG-W, super, allowances, RFB and termination payments before the FINAL event is sent to the ATO.

## What it does
- Reconciles each employee's YTD gross, PAYG-W and super against payroll reports
- Verifies STP Phase 2 income type, tax treatment code, allowance disaggregation, and country code
- Flags Reportable Fringe Benefits over the $2,000 grossed-up threshold
- Classifies termination payments (ETP, lump sum A/B/D/E)
- Produces a Word working paper for the file before the 14 July ATO deadline

## Prerequisites
- XBert account
- Client connected to an Australian-domiciled ledger with STP Phase 2 reporting enabled
- Full financial year payrun history posted

## Usage
After installing, type:

    /stp-finalisation

in any Claude chat (Desktop or Code).
