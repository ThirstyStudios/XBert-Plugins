# XBert Audit Evidence Pack

External-auditor-ready evidence pack driven by which XBerts fired on each transaction.

## What it does
- Resolves the period's linked audit XBert firings — the firings are the risk signal
- Builds a risk-weighted sample (more XBerts firing = higher weight) with minimum coverage on every material account
- Produces lead schedules per material account with sample items below
- Bundles the workpaper with cover page, risk-methodology note, partner sign-off, hyperlinks to every source XBert and source document, and a QMS block

## Prerequisites
- XBert account
- Client connected to a ledger
- Audit XBerts linked to the Audit Evidence agent in the Connect portal

## Usage
After installing, type:

    /audit-evidence-pack

in any Claude chat (Desktop or Code).
