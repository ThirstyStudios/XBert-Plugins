# XBert TPAR (AU)

Annual Taxable Payments Annual Report preparation for Australian clients in building, cleaning, courier, IT, road-freight and security industries. Due to the ATO by 28 August.

## What it does
- Pulls every supplier payment for the financial year and applies the TPAR industry filter
- Identifies reportable contractors, aggregates per contractor, separates GST from gross
- Validates ABNs (format and presence) and flags common errors
- Surfaces employees in AP, duplicate suppliers, missing ABNs, and sole-trader no-ABN withholding cases
- Produces a TPAR-ready summary table and Word working paper

## Prerequisites
- XBert account
- Client connected to an Australian-domiciled ledger
- Client operates in a TPAR-reportable industry (building, cleaning, courier, IT, road-freight, security)

## Usage
After installing, type:

    /tpar

in Claude Code or Claude Desktop.
