# XBert Anomaly Review

Review the period's anomaly XBerts and drive partner sign-off with an audit-ready evidence pack.

## What it does
- Resolves the period's linked anomaly XBert firings (duplicate journals, reversal pairs, vendor flips, round-tripping, period-jumps, unusual-day-of-week)
- Clusters findings by analytics pattern with likely root cause per cluster
- Captures partner sign-off per cluster (actioned / accepted-as-noise / escalated)
- Produces an evidence pack with hyperlinks back to every source XBert and journal line

## Prerequisites
- XBert account
- Client connected to a ledger
- Anomaly XBerts linked to the Anomaly Review agent in the Connect portal

## Usage
After installing, type:

    /anomaly-review

in any Claude chat (Desktop or Code).
