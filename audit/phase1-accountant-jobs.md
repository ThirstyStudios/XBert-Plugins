# Phase 1 — Accountant Jobs Catalogue (AU/NZ Public Practice)

## Executive Summary

This catalogue captures the period-end, statutory and tax workflows that a **qualified accountant** in an AU/NZ public practice runs day-to-day. The bookkeeper catalogue (sibling file) covers cash-cycle and ledger-hygiene work; this file picks up where that ends — at sign-off and BAS-cycle onwards.

Scope rules applied:
- **AU regulatory cadence assumed primary** (BAS/IAS monthly+quarterly, STP annual finalisation 14-Jul, FBT 1-Apr to 31-Mar, EOFY 30-Jun, TPAR 28-Aug, FY tax returns by 15-May/concession). NZ equivalents (GST 2-monthly, EOFY 31-Mar, FBT quarterly, IR3/IR4) noted where the workflow shape differs.
- Only workflows where **XBert can plausibly add value via MCP tools today** — pure tax-agent prep that never touches a connected ledger (e.g. ATO portal lodgement screen) is excluded.
- Rows that overlap meaningfully with the four shipped plugins are flagged so Phase 2 doesn't propose duplicates.
- Three additions beyond the seed list: **Director loan / Div 7A interest schedule**, **GST/PAYG instalment variation decision**, and **TPAR (Taxable Payments Annual Report)** — all are high-frequency public-practice deliverables that the seed list missed.

Total rows: **24**.

Coverage signal for Phase 2:
- **DataAgent** dominates (financial reports + period figures) — expected for accountant work.
- **XBertAgent** light — most accountant workflows are reviewer/preparer, not exception-resolution.
- Existing plugins match only at **trial-balance alignment**, **end-of-period dashboard** and **lock-date enforcement** — leaving the BAS/IAS/STP/FBT spine completely open for new plugins.

## Phase 2 Notes (for the auditor)

- **Engagement letter / scope review** was in the seed list but dropped — it's a practice-management task with no XBert-MCP value-add (Engagement-letter platforms own this; the work is contractual, not ledger-driven).
- **Workflows 1, 2, 4, 6, 22** (BAS / IAS / STP / SG / FBT) form a natural **"AU Compliance Calendar" plugin bundle** — same data spine, same lodgement-cycle UX. Strong candidate for one new plugin rather than five.
- **Workflows 8, 9, 10, 17, 18, 23** (TB alignment, BS review, FS pack, FAR rec, year-end provisions, intercompany) form a **"Year-End Working Paper" bundle**. Cowork plugin #5 skeleton already targets this — should be expanded.
- **Workflow 12** (end-of-period dashboard) is genuinely orthogonal to the four shipped plugins — needs a fresh build, cowork skeleton #3 is the right starting point.
