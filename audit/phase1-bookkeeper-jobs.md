# Phase 1 — Bookkeeper Jobs Catalogue

## Executive Summary

This catalogue captures **22 recurring workflows** that consume the bulk of a working bookkeeper's week at an Australian / NZ accounting practice. The scope is deliberately operational (the work a Senior Bookkeeper or BAS Agent does day-to-day), not advisory or compilation work.

Key observations for the alignment auditor (Phase 2):

- **Coverage gap — payroll**: Australian payroll (STP Phase 2, super, leave, terminations, payroll tax) is the single largest under-served domain. Six workflows (#8-#10, #17-#19) live here and only one has any existing plugin proximity. `Validation_PayrollReconciliation` and `Validation_SuperReconciliation` exist but no orchestrating plugin wraps the weekly/fortnightly cycle.
- **Coverage gap — chase / collections**: AR chasing (#7) is the highest-frequency revenue-impacting workflow most firms do badly. No existing plugin; clear candidate for a new "xbert-chase" plugin built on `Data_AgedReceivables` + `Workflow_SendReminder` + `Features_CreateClientTask`.
- **Coverage gap — onboarding / migration**: New-client onboarding (#16) and historical bank statement ingestion (#6) are project-shaped (one-off but multi-week), with almost no MCP tooling — most steps are manual file shuffling. Candidate for an "xbert-onboard" plugin.
- **Existing plugins land cleanly** on: bank rec (#1, xbert-reconcile), workflow / template review (implicit in #14, xbert-workflow-review). `xbert-capacity` and `xbert-pulse` are practice-manager tools, not bookkeeper tools — they don't surface in this list, which is expected.
- **MCP tool reach is strong on data + validation, weak on action**. Most workflows can *read* what they need but cannot *write* the deliverable (create payment file, lodge BAS, push payslip to employee). The Fabric_* and Workflow_* tools cover ~40% of the action surface; the rest is human-in-the-loop.
- **Two surprising additions** beyond the seed: **employee leave + STP Phase 2 reporting hygiene** (#17), **end-of-financial-year wash-up & STP finalisation** (#22) — both are seasonal but consume 20-40 hours per client when they hit.

Row count: **22**.
